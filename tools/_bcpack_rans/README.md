# Vendored MDU rANS entropy reference

From [bcpack-rs by Ahmet Dedeler](https://github.com/Ahmet-Dedeler/bcpack-rs),
revision `5bf5cc56ed56f1ababf1f9592300bd182ff90bd8` (the runtime codebook,
rank, and dictionary tables in `src/startup_stubs/bcpack_tables.h` and
`src/startup_stubs/bcpack_tables_bcn.inl` are pinned to revision
`c55c5fad539644b8cf5a705051df214291763fc0` from the same repository).
The code is licensed MIT OR Apache-2.0. Microsoft's model tables and per-lane
decoder port additionally carry the MIT notice in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
The complete upstream license terms are included: [MIT](LICENSE-MIT) and
[Apache-2.0](LICENSE-APACHE). The Apache file contains the full license
text, not only the short source-file notice.

- `__init__.py` extracts the constants, model and cycle-level entropy decoder
  from upstream `python/bcpack.py`, ending before `decode_symbols`. The module
  description and imports are replaced; the tables import is package-relative.
  Xbox2Windows adds a per-fragment counter and restores at most two omitted
  low zero bytes when a flushed fragment exhausts its physical byte budget.
  The next fragment's header is now accepted only after a flushed fragment
  returns to the rANS home state L; non-home intermediate states are
  rejected instead of silently discarded.
  This extension is checked against the existing 16-lane mode-6 fixture in
  issue #442 and trimmed/untrimmed reverse-encoded single-lane controls.
  It does not consume bytes beyond a fragment budget. Other decoder logic is
  unchanged. BC1 endpoint reconstruction, fitted endpoint
  windows, quadrant codebooks, archive readers and image output are excluded.
- `bcpack_tables.py` is copied unchanged from upstream `python/bcpack_tables.py`.
  It is generated from Microsoft's `silicon-rans` revision `2f6827d`.
  Do not edit the tables by hand. The test checks their canonical SHA-256.
- `vectors/synthetic_11.json` and `vectors/synthetic_12.json` are copied unchanged
  from upstream `tests/vectors/`. They were generated by the Rust
  `encode::synthetic_bc1` function with 64 and 700 blocks respectively, seed 11
  or 12, and a maximum fragment size of 150. They contain synthetic streams,
  expected lane symbols and BC1 digests; this contribution uses only the
  entropy stream and symbols, without reconstructing BC1 blocks.

The upstream `python_vectors` Rust test reproduces both vector files:

```text
cargo test --offline --no-default-features python_vectors
```

The public Xbox2Windows wrapper is `tools/bcpack_symbols.py`. It bounds input and
output sizes, validates lane widths, checks exact output counts and rejects
non-zero trailing bytes. The vendor decoder's callback source is retained for
upstream comparison but is not exposed by the wrapper.

To refresh, select an explicit upstream revision, repeat the extraction above,
preserve notices, compare source changes and rerun `tests/bcpack_symbols_check.py`.
